# P6 Schedule Analyzer

An enterprise-grade, cloud-ready schedule intelligence platform for Primavera P6 XER and MS Project XML files.

## 🚀 Features
* **Multi-Format Parsers:** Supports `.xer`, P6 `.xml`, and MS Project `.xml`.
* **Advanced Health Analytics:** 622+ automated checks across DCMA 14-Point, DOE PM-30, NASA NPR 7120.5, GAO, and AACE standards.
* **EVM & Resource Analytics:** S-Curves, SPI/CPI, labor histograms, and cost burn rates.
* **Variance Comparison:** Dual-schedule comparison detecting slipped tasks and logic changes.
* **Multi-Period Trends:** Track schedule drift across up to 12 updates.
* **AI Executive Narrative:** Auto-generates written executive briefings.
* **Enterprise SaaS Ready:** Multi-tenant workspaces, RBAC, PostgreSQL, and AWS S3 support.

## 🛠️ Tech Stack
* **Backend:** Python, Flask, SQLAlchemy, Pandas
* **Frontend:** HTML5, CSS3, JavaScript, Chart.js, DHTMLX Gantt
* **Reporting:** ReportLab (PDF), OpenPyXL (Excel)

## 🏃 Local Development
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the application: `python app.py`
4. Access at `http://localhost:5000`
